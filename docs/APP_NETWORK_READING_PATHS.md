# Hospital Management System — App-Network Reading Paths

This page connects documentation for requirements review and learning. Links do not establish implemented integrations. The portfolio comprises four manufacturing design briefs, six documentation-first service concepts, and two incomplete educational prototypes. Neither gateway is selected as canonical. No deployment, compatibility, security, performance, regulatory, or customer-outcome claim is made. Use synthetic examples only.

## Repository-specific review worksheet

This incomplete Java Servlet/JDBC educational prototype is not a clinical or hospital-ready system. Never use real patient, medical, billing, or staff information.

1. Map a fictional registration-to-appointment administrative handover.
2. Identify required privacy, permission, persistence, and date-handling checks without claiming they exist.
3. Record incomplete behavior and obtain a technical review before any isolated synthetic demonstration.

## Suggested written reading paths

- Manufacturing: begin with the four manufacturing design briefs below and record ownership, evidence needs, and unresolved requirements before discussing software.
- Service concepts: use the six documentation-first concepts to discuss boundaries and responsibilities; do not assume they connect to each other.
- Educational prototypes: use Banky and Hospital Management System only for synthetic learning exercises, subject to their existing safety warnings.
